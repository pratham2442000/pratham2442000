## 🛠️ Repository Tools & Scripts Overview

This repository houses custom engineering utilities for job hunting, university archives, and automated application pipelines:

### 1. 🇳🇱 [IND Sponsor Job Hunter & Analyzer](sponsor_jobs/README.md)
An automated discovery and tracking system designed for the Dutch tech job market:
- **IND Public Register Sync**: Continuously tracks all 12,900+ official Dutch Recognised Sponsors for Highly Skilled Migrant visa eligibility.
- **Multi-Platform ATS Scraper**: High-throughput scraper covering 9 ATS platforms (Greenhouse, Lever, Ashby, Workday, Recruitee, SmartRecruiters, Personio, etc.) plus Dutch tech feeds.
- **Intelligent Profile Matching**: Scores roles (0–100%) against AI/ML, Computer Vision, Perception, and MLOps background, filtering strictly for EU/Netherlands roles.
- **Application Tracker & Web Dashboard**: 1-click automatic apply tracking (`[Apply ⚡]`), persistent SQLite database, terminal CLI (`python cli.py apply/applied`), and a local web dashboard (`python cli.py web`).

### 2. 🎓 [Brightspace Course Backup Tool](brightspace_backup/README.md)
An automated archival utility for D2L Brightspace (TU Delft):
- **Full Course Content Archival**: Recursively downloads lecture slides, code repositories, assignments, and reading materials while preserving the complete folder structure.
- **Student Submissions & Feedback**: Preserves your submitted work, timestamps, instructor written feedback, rubric scores, and graded attachments.
- **Grades, Quizzes & Announcements**: Exports your personal gradebook to Markdown/JSON, archives quiz attempts, and saves all course announcements.
- **Video & Stream Support**: Automatic lecture video downloading via `yt-dlp` or markdown link bookmarking.

### 3. 📄 Tailored CV & Cover Letter Generation Pipeline
A modular, high-impact LaTeX application suite:
- **`cv.tex`**: Two-page modern resume emphasizing AI/ML research, perception, and distributed systems.
- **`cover_letter.tex`**: Modular cover letter generator.
